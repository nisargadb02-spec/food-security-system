# 🍲 Food Security System – India Hunger Analysis

## 📌 Project Overview
This project analyzes food insecurity and hunger trends in India using sample data inspired by real-world reports from global organizations.  
It visualizes undernourishment and poverty trends and demonstrates how data science can support better food distribution systems.

---

## 🎯 Problem Statement
Millions of people in India still face hunger and food insecurity.  
This project explores:
- How hunger trends change over time
- Relationship between poverty and undernourishment
- Data-driven insights for possible solutions

---

## 📊 Features
- Data analysis of hunger trends in India
- Visualization of:
  - Undernourished population over years
  - Poverty rate trends
- Clean and structured dataset handling
- Interactive Streamlit dashboard
- Simple ML/data analysis pipeline

---

## 🛠️ Tech Stack
- Python
- Pandas
- Matplotlib
- Streamlit
